# Source and scope

The A2 project is derived from the assisted A1-aligned Lab4 tutor, baseline commit 65fd133, dated 28 October 2026. It is not the earlier email prototype. Original source files are retained locally; their import fingerprints follow. This repository begins with the actual A2 preparation rather than presenting copied history as new student work.

Only app.py, model.py, problems.json, the tutor tests and the tutor interface were adapted. The teaching corpus, third-party starter helpers, images and unrelated local scheduling path are outside this package. The inherited fixed equations and steps are unchanged. No private A1 manuscript, account identifier or API key is included.
