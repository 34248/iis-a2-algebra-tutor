# Research readiness and the A1 question

Status: implemented interaction prototype, no participant study. The submitted A1 proposed comparing an attempt requirement plus gradual release against immediate identical solution steps, then examining later unaided work, effort and possibly retention. This project can support that comparison; it has not established an educational effect.

## Current support and limits
Both modes use the same authored problems and help. The new equation-equivalence checker can be switched off in both conditions and the setting is recorded. Nine pairs include increasingly involved linear equations, but a student who already knows this material may still score near the ceiling. Prior knowledge must be assessed rather than assuming that the tasks are sufficiently difficult for university students.

The free-practice interface lets users choose items, switch modes, retry and receive immediate correctness feedback. It does not implement random assignment, a locked research sequence or a delayed-feedback first-response post-test. Ordinary practice data must not be described as a controlled experiment. Session IDs are not participant IDs. Software demonstrations cannot be substituted for observations of recruited participants.

## Proposed future protocol
1. Use an appropriate course research arrangement with clear information about participation, records and withdrawal. Conduct a brief unaided knowledge check to establish a suitable starting level.
2. Define allocation before collecting outcomes. Keep training tasks, their order, checked help content and extra-feedback setting consistent across the two conditions. The existing switch supports feedback control; allocation and sequence enforcement remain future work.
3. Record practice use and time. Use unseen unaided questions for the main procedural outcome, with a predefined rule for first valid responses and feedback deferred until the test is complete. Current retry practice is not that post-test.
4. Add explanation questions with a defined rubric and suitable human checking to assess conceptual understanding. The implemented equivalence checker does not score the learner's reasoning. Collect an appropriately described effort measure and pre-plan any later retention check.
5. Report the sample, missing data and uncertainty. A small feasibility pilot can expose workflow problems without being sufficient to establish an educational benefit. A nonsignificant difference does not establish equivalence, and the combined attempt requirement and release sequence cannot be separated by this design.

The research purpose is to examine whether the interaction changes later performance and cost. It is not to promise that gradual help wins. A2 permits prototypes and simulations, but requires accurate scope, developed interactions and a reasoned explanation. This report therefore marks research activities as planned.
