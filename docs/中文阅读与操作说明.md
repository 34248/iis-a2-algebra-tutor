# A2 中文阅读与操作说明

审阅版：a2-review-v3。这份 A2 延续已交的 AI 辅导 A1，用完全相同的代数题和解答内容，比较先尝试再逐步看提示，以及立即看全部解答。原 Lab4 文件保留不动。

运行 project/run.cmd，按窗口提示打开 http://127.0.0.1:8764 。启动器优先用这台电脑已配置的 Python 3.12；其他电脑需要 Python 3.12 或更新版本。不需要 API key。

建议检查以下操作：

1. 选 A01、gradual、revised 并开始。未记录尝试时，提示按钮应不可用；写自己的尝试并记录后，每点一次提示只增加一个步骤。
2. 切到 immediate 并重来，比较是否与逐步模式最终得到的三步相同。
3. 输入不完整的 `2x + = 11`，确认修改版不给解答；改正后可以重来。baseline 是故意保留的错误演示。
4. 在无提示题输入字母或 `1/0`，应得到格式提示，记录中用 unassisted_invalid、正确性留空；有效数字答案才记为正确或错误。
5. 做 T01，输入 `3` 应正确；换到 T02 应清除旧答案和反馈。检查期间改写答案，界面不应把旧判断套到新输入上。
6. 导出 CSV，核对模式、事件、次数和无提示答案结果。服务器副本保存失败时会明确提示，内存中的 CSV 仍可下载。

本轮优化包括严格核对辅导返回、阻止自由回复绕过步骤限制、统一数字和分数检查、让状态更新和记录保存保持一致，以及停止在默认日志中输出尝试原文。验证通过 27 项代码检查与 22 项浏览器检查，后者包含刻意设置的保存失败。

实际实现：网页、后台、会话状态、内容核对、输入纠错、数字检查、记录和导出。模拟：固定内容回答函数，没有接实时大模型。计划：参与者分组、前测、概念评分与保持测试。所有演示记录都不是参与者研究数据。
