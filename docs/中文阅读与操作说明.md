# A2 怎么看和怎么演示

这份 A2 延续已提交的 AI 辅导 A1：相同的代数题和解答内容，一种模式先写尝试再逐步看提示，另一种立即看全部解答。原 Lab4 保留不动。

先运行 project/run.cmd；如果电脑找不到 Python，可以用已配置的 Python 运行 project/app.py --port 8764。打开 http://127.0.0.1:8764 。

建议亲自走三遍：
1. 选 A01 和 gradual，开始后写一句尝试，点 Next hint。每次只显示一个步骤。再切换 immediate 并重新开始，比较是否是完全相同的三步。
2. 输入不完整的 2x + = 11。revised 会要求补全；改正再开始可以恢复。baseline 是故意保留的错误演示，不是商用 AI 的真实错误记录。
3. 做 T01 新题，不显示提示。用 Export this session as CSV 下载本次操作记录。CSV 记录操作，不是证明学得更好的实验结果。

真实实现：网页、后台、状态、内容核对、输入纠错、数值检查和导出。模拟：辅导回答由固定内容函数提供，没有接实时大模型。计划：前测、参与者分组、概念评分和保持测试。
