# A2 新版系统怎么试

版本 a2-review-v5。9 道练习与 9 道配对新题覆盖整数、负数、分数和多步骤变形。原 Lab4 未修改。

运行 project/run.cmd 会打开本地浏览器。直接命令为 `python app.py --port 8764 --open`，需要 Python 3.12 或更新版本。端口被占用时会换一个空闲本地端口，按窗口显示的地址进入。

1. 选 A01，保留 Try first，开始。在工作框输入 `2x = 8`，点 Check this equation。应显示等价；此时还没有释放例题步骤。再点 Reveal next step，只增加一步。
2. 把工作改成 `2x = 14` 再检查。应提示改变了原题的解，不给最终答案。输入文字解释可以单独点 Record explanation，不会评分推理质量。
3. 选 A09 并开始。原题包含分式；输入 `2(x-1) + 3x = 24` 可以检查，再按需请求提示，最多六个步骤。
4. 在最终答案框填 `26/5`，应显示完成；点新题按钮会转到 T09。这个新题不给步骤，填写 `6` 应正确。允许重试，因此不能把它当受控后测。
5. 打开 Demo controls，可在两种模式同时关闭 Allow equation feedback，再开始。后台也会禁止额外方程检查，记录中包含这个设置，便于保留 A1 的较窄比较。
6. 点 Download CSV，核对事件、模式、显示步骤和检查结果。文件不保存工作原句。所有随包示例是开发者演示，不是参与者数据。
